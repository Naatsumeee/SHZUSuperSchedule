# 构建环境搭建

这一节是本项目**所有构建的基础**。环境搭好后再没动过，出问题先对照这里。

## 版本组合（唯一验证过的）

```
Gradle                    9.7.1   → android-toolchain/gradle/gradle-9.7.1
AGP                       9.4.0
compileSdk                37
minSdk / targetSdk        24 / 36
Compose Multiplatform     1.11.1
MiuiX                     0.9.3   (miuix-ui / miuix-preference / miuix-icons)
androidx.activity-compose 1.10.1
JDK                       17
```

## 为什么是这些版本（每个都是踩出来的）

- **Gradle ≥ 9.6.0**：AGP 9.4.0 的硬性要求。本机原来是 9.3.1，不够。
- **不能退回 AGP 8.x**：AGP 8.13.2 与 Gradle 9.6+ 不兼容（用了已移除的内部 API）。
  所以 AGP 9.x + Gradle 9.6+ 是**唯一可行组合**。
- **AGP 9.0+ 内置 Kotlin**：必须**移除** `org.jetbrains.kotlin.android` 插件，否则报错。
  保留 `org.jetbrains.kotlin.plugin.compose` / `org.jetbrains.compose` / `serialization`。
- **compileSdk 37 是伪造的**：miuix 0.9.x 的 aar-metadata 里 `minCompileSdk=37`，
  但当时 `sdkmanager` 里**根本没有 android-37**。
  解法：复制 `platforms/android-36` 为 `platforms/android-37`，
  改 `source.properties` 里 `AndroidVersion.ApiLevel=37`。
  代码不使用 37 新 API，可正常编译。
- **CMP 1.11.1 而不是 1.12.0**：1.12.0 对 compileSdk 37 的 compose 依赖更多；
  1.11.1 与 miuix 0.9.3 的依赖一致。
- **activity-compose 1.10.1**：1.13.0 要求 compileSdk 37 的更多依赖。

## 网络极慢（~100 KB/s）

Gradle 默认超时会导致下载 Kotlin 编译器中断。

- `gradle.properties` 加：
  ```
  systemProp.org.gradle.internal.http.connectionTimeout=180000
  systemProp.org.gradle.internal.http.socketTimeout=180000
  ```
- 缺的 jar 用 `curl -C -` 断点续传手动下载，放进
  `gradle-home/caches/modules-2/files-2.1/<group>/<artifact>/<version>/<sha1>/`
  （sha1 用 `Get-FileHash -Algorithm SHA1` 算）。

## 内存紧张（机器 15GB，可用常 < 4GB）

```
org.gradle.jvmargs=-Xmx1536m -XX:MaxMetaspaceSize=512m
kotlin.daemon.jvmargs=-Xmx768m
org.gradle.workers.max=1
org.gradle.parallel=false
```

⚠️ **内存给太大会导致构建中途被 OOM 杀掉**。
现象很有迷惑性：**日志里没有任何错误，约 2 分钟后中断**。
看到这种情况先怀疑内存，不要以为是网络或依赖问题。

## 构建命令

```powershell
$env:JAVA_HOME        = "C:\Users\xutia\WorkBuddy\android-toolchain\jdk17"
$env:ANDROID_HOME     = "C:\Users\xutia\WorkBuddy\android-toolchain\android-sdk"
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME
$env:GRADLE_USER_HOME = "C:\Users\xutia\WorkBuddy\android-toolchain\gradle-home"
# 清空所有 PROXY 环境变量（直连）
cd shzu_class_km
& "C:\Users\xutia\WorkBuddy\android-toolchain\gradle\gradle-9.7.1\bin\gradle.bat" assembleRelease --no-daemon --console=plain
```

## 编译期踩过的 Kotlin 坑

- `"$sections小节"` → 中文是合法 Kotlin 标识符字符，被解析成标识符 `sections小节`
  → 必须 `"${sections}小节"`
- `"$startMinutes()"` → `Function invocation 'startMinutes()' expected` → 必须 `"${startMinutes()}"`
- 不要 `import androidx.compose.foundation.layout.weight`（internal API）
