## 与 memory 的分工

- `memory/` = **过程**（当时怎么想的、试了什么、错了几次）
- `thinking/` = **结论**（下次直接照做）

两者不要互相替代。改代码前看 `thinking/`，想知道为什么看 `memory/`。
