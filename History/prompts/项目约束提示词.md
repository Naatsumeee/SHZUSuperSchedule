# 项目约束提示词（跨版本一直生效）

这些是用户明确说过、且**在后续所有版本中都必须遵守**的约束。
改任何 UI / 交互前先过一遍这份清单。

## 视觉

- **界面用 MiuiX 风格**（`top.yukonga.miuix.kmp`），**不要橙色主题**。
- **不要无意义的名句 / 引言 / 标语**（用户明确要求去掉页面标语）。
- **倾向紧凑排版**：标题字号与留白要压，但大标题要保留。
- 大标题统一用 MiuiX 规范字号与留白；「今日课程」与「本周课表」的大标题
  字号与留白**完全对齐**。
- 配色走低饱和、可区分的路线（15 色色板）；莫兰迪 / 石墨灰蓝整体提亮过一轮；
  新增冷色调配色集「冰川冷调」。
- 自定义文字颜色要**校验与底色的对比度**，看不清时提供「自适应文字色」。

## 交互

- **滑块 / 配色这类易误触的控件收进二级菜单**。
- 二级页面用 `SubPageTopBar(title, onBack)`，**返回按钮在页面顶部**而不是页尾。
- 二级页返回是「返回上一级」而不是退出应用。
- **预测性返回已移除**（跟手预览体验不佳），回归标准返回处理 + 过渡动画。
- 连续触发的轻提示不要排队堆积（后一条先收掉前一条）。

## 功能取向

- 课表是**本地优先**：以 JSON 文件持久化，下次打开直接读，不重复导入。
- 导入课表前**严格校验**，失败要给出具体原因。
- 「课程数量」按**课程名去重的学科门数**统计，不是节数。
- 今日页节数按科目统计，一天最多 5 门。
- 冲突判定只看**本周内同课时**，跨周不算冲突。

## 工程与协作

- **每次改完必须编译验证**，不能只写代码不构建。
- 改完 Kotlin 代码自检字符串模板（见 `../../PROJECT_PROMPT.md` 的红线部分）。
- **用户说自己会测试时，就交付并停止**，不要继续自作主张地改。
