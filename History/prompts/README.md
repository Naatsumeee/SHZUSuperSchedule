# prompts — 提示词归档

保存这个项目的**需求是怎么被提出来的**，以及**反复生效的约束型指令**。

| 文件 | 内容 |
|------|------|
| [用户指令序列.md](用户指令序列.md) | 按时间整理的用户需求原话 / 要点，含每条对应的产出 |
| [项目约束提示词.md](项目约束提示词.md) | 跨版本一直生效的硬约束（视觉风格、署名、交互偏好等） |
| [交接提示词.md](交接提示词.md) | 换 Agent 时可以直接贴的那段话（与根目录 `PROJECT_PROMPT.md` 同源） |

## 为什么要存这个

代码只能告诉你「现在是什么样」，提示词能告诉你「为什么是这个样」。
例如「底栏模糊半径要渐变」这条，如果只看代码会以为是随手写的参数，
看了提示词才知道是用户明确反馈「模糊过于生硬」之后的针对性修改。

## 完整性说明

- 本目录内容**从 `../memory/` 工作日志中整理**，不是原始对话逐字导出，
  因此可能有遗漏，但每一条都能在工作日志里找到对应记录。
- 记录时保留需求**要点**而非逐字，因为日志本身就是摘要体。
