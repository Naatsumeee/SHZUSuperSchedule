# 石河子大学教务系统课表爬虫

登录学校统一身份认证（CAS）+ 短信二次认证，抓取强智教务系统课表，导出 JSON。

## 抓取字段

课程名称、教师、上课地点、教学楼、星期、节次、小节、时间段、周次、班级、备注等。

## 环境要求

- Python 3.10+
- 需要能访问校内网络（`jwgl.shzu.edu.cn` / `authserver.shzu.edu.cn`）

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

```bash
# 抓当前学期，导出到 课表.json（默认）
python jwgl_spider.py

# 指定学期
python jwgl_spider.py --semester 2025-2026-1

# 指定输出文件
python jwgl_spider.py --out my_schedule.json

# 命令行直接传账号密码（不交互）
python jwgl_spider.py --username 20241014336 --password 你的密码

# 查看所有可选学期
python jwgl_spider.py --list-semesters
```

运行后会：

1. 用学号密码登录 CAS；
2. 自动向手机发送**短信验证码**，控制台提示输入；
3. 验证通过后进入教务系统抓取课表；
4. 导出 JSON 文件并在控制台预览。

## 技术要点

- **CAS 密码加密**：复现统一身份认证前端 `encrypt.js` 的 AES-CBC 加密（64 位随机前缀 + PKCS7 填充 + Base64）。
- **短信二次认证（MFA）**：调用 `getDynamicCodeByReauth.do` 发验证码，`reAuthSubmit.do` 提交。
- **TLS 兼容**：`jwgl.shzu.edu.cn` 服务器 TLS 较旧，Python 标准 `requests`（OpenSSL 3.5+）握手会因后量子密钥交换 `X25519MLKEM768` 失败。改用 `curl_cffi`（`impersonate="chrome"`）模拟 Chrome TLS 指纹即可正常访问。
- **课表解析**：解析强智系统 `xskb_list.do` 页面中 `id="timetable"` 的周课表网格，从每个单元格的 `kbcontent` 详情块提取课程信息。

> 说明：账号密码仅用于登录你自己的教务系统抓取个人课表，请妥善保管，勿泄露或用于他人账号。
