### 关键技术结论（可复用）

1. **系统架构**：`jwgl.shzu.edu.cn` 是**强智教务**（jsxsd 路径），不是正方。课表数据页 `/jsxsd/xskb/xskb_list.do`，解析 `id="timetable"` 表格中每个 `kbcontent` div（同格多门课用 `-----` 分隔）。
2. **登录链路**：`jwgl` 首页 302 → CAS 统一认证 `authserver.shzu.edu.cn`（金智/Wisedu），密码用 AES-CBC 加密（随机 64 位前缀 + 盐 `pwdEncryptSalt` + PKCS7 + Base64）；登录成功后若访问教务系统触发**短信二次认证(MFA)**（`getDynamicCodeByReauth.do` 发码 → `reAuthSubmit.do` 提交，`reAuthType=3`）。
3. **关键坑（TLS）**：`jwgl.shzu.edu.cn` 老 TLS，Python 标准 requests + OpenSSL 3.5.7 握手必失败（`SSLV3_ALERT_HANDSHAKE_FAILURE`，疑似后量子密钥交换 X25519MLKEM768 导致老设备不识别）。**解法：用 `curl_cffi`（`impersonate="chrome"`）**，一次成功。curl.exe(Schannel) 也能通但 Python 侧不可用。
4. **环境坑**：本机 Bash 工具的 PATH 残缺（`dirname`/`mkdir`/`ls` 都 not found），必须用 PowerShell + `curl.exe` / 绝对路径 python；PowerShell 直接 `Write-Output` 不回显，需 `Out-File` 后再用 Read 读。

### 关键坑（App 构建）

1. **沙箱拦截**：Android SDK 安装（写 `.temp`）和 Flutter 大 zip 解压都会被沙箱拦截，必须 `dangerouslyDisableSandbox`。curl 下载、dart pub get 可正常走代理。
2. **Flutter 下载超时**：1.79GB 超时（curl `--max-time` 限制），用 `curl -C -` 断点续传解决。
3. **flutter.bat 工具异常**：`flutter pub get`/`flutter analyze` 输出为空 + exit 1，但直接调 `flutter/bin/cache/dart-sdk/bin/dart.exe pub get/analyze` 成功（解决：直接用 dart.exe）。
4. **Gradle 代理**：Gradle 不读环境变量代理，需在 `android/gradle.properties` 配 `systemProp.http/https.proxyHost=127.0.0.1` + `proxyPort=2253`。
5. **flutter_local_notifications 18**：需 (a) core library desugaring（`isCoreLibraryDesugaringEnabled=true` + `desugar_jdk_libs:2.1.4`）；(b) `zonedSchedule` 必须传 `uiLocalNotificationDateInterpretation`。
6. **Dart 编译错误**：`enum` 不能声明在 class 内部（LoginResult 要移顶层）。

### 关键坑（按重要性）
1. **网络**：本环境可**直连外网**（dl.google.com/services.gradle.org/pub.dev 都直连 200），系统 http_proxy=127.0.0.1:2253 反而对 Java 程序报 Connection refused。→ 构建前必须 Remove-Item 所有代理环境变量，直连。curl 下载大文件也要加 `--noproxy "*"`。
2. **flutter.bat 工具异常**：`flutter pub get/analyze/build` 输出空+exit1，改用 `flutter/bin/cache/dart-sdk/bin/dart.exe` 直接跑 pub get/analyze；构建用本地 gradle.bat 而非 flutter build（绕开 flutter 工具的 pub get 卡死）。
3. **沙箱**：Android SDK 安装、Flutter/NDK 大文件解压都会被沙箱拦截（必须 dangerouslyDisableSandbox）。
4. **NDK**：Flutter 3.47 强制要 NDK 28.2.13676358（且 CMake 测试所有 ABI）。sdkmanager 装 NDK 会卡死（下载 7MB 就断）；**解法：curl 直连下载 android-ndk-r28c-windows.zip（713MB），tar 解压到 android-sdk\ndk\28.2.13676358\**。注意首次 tar 解压 arm-linux-androideabi 目录为空（exit1），需重解压验证 crtbegin_dynamic.o 存在。
5. **gradle .lock "拒绝访问"**：残留损坏锁状态导致。**解法：删光 `gradle-home\caches\9.3.1\` 整个目录再重跑**（依赖 jar 在 modules-2 里不用重下，只重做 transform）。已验证 Java FileLock 本身在沙箱下正常。
6. **kotlin-stdlib-jdk8 jar 缺失**：只缓存了 pom，需手动 curl 下载 jar 放到 `gradle-home\caches\modules-2\...\1.8.20\<sha1>\`（sha1 用 Get-FileHash 算）。
7. **Flutter 3.47 默认**：compileSdk=36/minSdk=24/targetSdk=36；gradle 9.3.1（all 版，直连下载 bin 版即可）；需 core library desugaring。
