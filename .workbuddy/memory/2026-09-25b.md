## 一、方案 1：解析器单元测试（commit `8ef8188`）

### 为什么做
项目原本 `app/src` 下**只有 `main`，零测试**。而历史上最痛的三个 bug 全在
`JwglQueryParser`，且**编译都能通过** —— 只能靠真机验证：
改代码 → 2 分钟构建 → adb 装机（MIUI 还不保证替换）→ 登教务点查询，一轮十几分钟且要联网。

### 关键技术障碍与解法
`JwglQueryParser` 是纯逻辑（Jsoup 解析、无状态），本该能跑 JVM 测试，
但它 `import android.util.Log` —— android.jar 里方法体全是 `Stub!`，
JVM 测试一调用就抛 `RuntimeException: Stub!`。

**解法**：新增 `data/Logger.kt` 接口 + `LogcatLogger`（生产）/ `NoopLogger`（测试默认）。
- 默认空实现，测试**零初始化**即可跑，少一个"忘初始化"的坑；
- 11 处 `Log.x` 改为 `Logger.x`，**算法一行未动**（diff 可逐行核对）；
- 命名避开 `androidx.window.core.AndroidLogger`（同名冲突）。
  第一次编译正是踩到这个：接口 companion 里 `@JvmStatic` 加在 `private set` 的属性上
  → `JVM_STATIC_ON_NON_PUBLIC_MEMBER`，改为普通 `private var` + 公开函数即可。

### 夹具（关键资产）
`app/src/test/resources/jwgl/`：
- 四份**真机抓包**（从 `History/logs/device/` 拷来）；
- `exam_grade_reconstructed.html` —— 等级考试结果 iframe 当时**没落盘**，
  按 MEMORY.md 与 `History/thinking/教务查询三类结果.md` 记的真实结构复刻，
  文件头注明来源与"拿到真抓包应直接替换"。

### 两个数据要点（我最初都写错了，代码是对的）
1. `2026-09-01` 是**周二**，所以 `guessStartDate` 推 9 月第一个周一得 `09-07` 而非 `09-01`。
2. 等级考试第二层表头的真实值形如 `笔试 机试 总成绩 笔试 机试 总成绩`
   —— 两组**用重复子列名**（这也是 `isStrayHeaderRow` 判据③「行内有复读值」的来源）。
   我第一版复刻成不重复的名字，导致 `isStrayHeaderRow` 不命中、测试失败。

**教训：复刻夹具时必须逐字对照文档里的真实取值，不能"按合理的样子"编。**

## 二、方案 3：版本号单一来源（本轮）

`BETA-v1.4` 原先写在**两处**：`build.gradle.kts` 的 `versionName`
和 `SettingsPage.kt` 的 `const val APP_VERSION`。发版漏改一处就对不上。

改为：`buildConfig = true` + `val APP_VERSION = BuildConfig.VERSION_NAME`。
- 「关于」页与所有调用点的显示行为**完全不变**（`BuildConfig.VERSION_NAME` == `"BETA-v1.4"`）；
- 发版现在只需改 `versionName` 一处，`CHANGELOG` 仍要手动加条目（那是文案，不是版本号）；
- 验证：dex 里 `BETA-v1.4` 出现 1 次，`BuildConfig` 已链入。

## 三、方案 4：仓库瘦身（本轮）

### 🔴 核查推翻了我自己的原方案
原方案说「Backups 只留最近 2 个 APK，旧包以 Release 为归档」。
**动手前核查发现这不成立**：全仓 9 个 APK 里，
**只有 v1.3.2 与 v1.4 真的在 GitHub Release 上有附件**（用 sha256 逐一比对确认），
其余 7 个（含 57 MB 的 Flutter 原型）删掉即永久丢失。

进一步核查发现更危险的一点：**Flutter 原型被 `.gitignore` 明确排除、从未提交过**
（为了绕过 GitHub 的 50 MB 单文件上限），所以它**连 git 历史里都没有**，
不在工作区就等于消失。

把风险和选项摆给用户确认（用户答复"我另有备份"）后，才执行删除。

### 执行结果
- 删除全部 9 个 APK：`Backups/` 从 **167 MB → 68 KB**；
- **10 份版本说明 md 一份未动**；
- 每个包（含已移出的）的**字节数 + sha256 全部记入 `Backups/README.md`**，
  保证二进制不在也能辨认与校验；
- `.gitignore` 里为 Flutter 原型单开的那条特例规则随之删除（已无意义）。

### 一个必须写下来的认知
`git rm` **不会缩小仓库** —— 已删 APK 的 blob 仍留在 `.git` 的 pack 里（209 MB）。
要真正缩体积必须 `git filter-repo` 重写历史，那会改变**所有提交哈希**、
影响已发布的 tag。**本项目不做这个权衡**，体积只靠"不再往历史里堆二进制"来控制。
这条已写进 `Backups/README.md` 与 `PROJECT_PROMPT.md` §8，避免下次有人白忙一场。
