### 2. 查询页三类结果改成**分类型卡片**（新文件 `ui/QueryCards.kt`）
原先只有一套通用版式（首字段当标题 + 其余按「字段名 → 值」排），

- **考试安排 ExamCard**：`考试时间`、`考场` 加粗放最上方（用户要求"醒目显示"），

  `2026年11月28日（第13周周六） 10:00-11:30` —— 用 `Regex.replace` 逐段替换日期，
  同一格里塞了多场考试（补考/连考）时每一段都会带上自己的周次。
- **课程成绩 ScoreCard**：课程名当标题（加粗 16sp），成绩右对齐放大到 22sp 加粗；
  **不及格标红**。`开课学期 / 课程编号` 收进卡片底部一行 11sp 小字脚注。
- **等级考试 GradeCard**：考级课程当标题加粗；`分数类成绩 / 等级类成绩` 每组只留**有数据的那条**；
  排序见下。

**取值一律按表头关键词查找，不写死列序号** —— 与 `JwglQueryParser`「不做逐字段建模」一致。

### 3. 🔴 等级考试「笔试」空卡片的根因（用户反馈）
用户说「第一条以'笔试'为小标题的无意义的内容」。根因是：
强智等级考试成绩表是**双层表头**（`分数类成绩` / `等级类成绩` 下再分 `笔试 / 机试 / 总成绩`），
**第二层表头被写在 `<tbody>` 里**而不是 `<thead>`，于是被当成普通数据行收了进来。
这一行前两列（序号 / 考级课程）是空的，第一个非空单元格就是「笔试」，
卡片标题因此渲染成「笔试」，后面跟着「机试」「总成绩」——整张卡片没有一个真实数据。

修法两层：
- `JwglQueryParser.isStrayHeaderRow(cells, headers)`（新增，public）：判据是
  ① 非空单元格 ≥ 2；② **整行一个数字都没有**（真数据行几乎必然带序号/日期/分数）；
  ③ 行内有复读值（`笔试 机试 总成绩 笔试 机试 总成绩`）或每个值都能在表头里找到。
  `readTable` 里跳过。
- `QueryStore.sanitize` 也用它清**老存档** —— 光改解析器救不了已经存进 json 的脏行，
  必须在读取时清，用户不刷新也能立刻看到正确结果。
  日志：`存档清理：移除 N 行误入数据区的表头记录`。

### 4. 等级考试排序（`gradeRowsSorted`）

无时间的排在各分类末尾。分类靠 `考级课程名` 里的「四级/六级/一级/二级」关键词判定。

### 5. 查询页大标题与设置页对齐（第 4、7 条）
`PageHeader(title = "查询", miuixDefault = true)` —— 走 MiuiX 规范的 `title2`（**24sp**）
+ `start/end 16dp, top 16dp, bottom 8dp`。查询页外层 Column 已经是 `padding(12,12,4,…)`，
所以落点正好是 **左 28dp / 上 20dp**，与设置页逐像素一致。
同时删掉 subtitle（"从教务系统读取考试安排与成绩"）—— subtitle 会让标题整体下移，正是割裂感来源。

### 6. 「今日课程」「本周课表」标题对齐（第 5 条）
**原来的水平方向已经对齐**（今日 10+6=16，课表 16+0=16），
但**垂直方向差 4dp**：今日页标题上方还叠了 LazyColumn 的 `contentPadding top=4dp`，
课表页外层没有额外内边距。修法：课表页标题前补 `Spacer(Modifier.height(4.dp))`，两边都落在 12dp。

### 7. 周视图：星期/日期条跟随 pager 滚动 + 「本周」标签前置（第 6 条）
`WeekStrip` 与星期表头原来放在 `Column` 里、与 `HorizontalPager` **平级**，
所以翻周时只有下面的格子动，上面那两条纹丝不动。
修法：把这两条**挪进 pager 的页内容**（`Column { WeekStrip; WeekdayHeader; Box(weight 1f){ WeekGrid } }`），
由 pager 统一驱动 —— 像素级同步，且**不需要手算 `currentPageOffsetFraction`**
（那个 API 的正负号约定容易搞反，手算出来的偏移量还很难验证）。
「本周」蓝色胶囊从「第 N 周」**之后**挪到**之前**。

### 等级考试的真实结构

thead **只有一行**，父列用 `colspan` 铺开：`1+1+4+3+1+1 = 11` 列；
**真正的子列名（笔试 / 机试 / 总成绩 …）单独占了 `<tbody>` 的第一行**。

因此两个后果：
1. 那行前两列空、第一个非空单元格是「笔试」→ 界面凭空多出**标题为「笔试」、内容全是
   「机试 / 总成绩」的空卡片**；
2. 4 列「分数类成绩」同名 → 无法分辨哪列有分数 → 只能"取第一个非空值"，
   于是挑中教务表示"这项没成绩"的 **`0`**（用户反馈：分数一般不为 0）。

### 修法：不是丢掉那一行，而是**当第二层表头用**

`JwglQueryParser.repairStrayHeader(headers, rows)`：
按列号把子名拼到父名后面（`分数类成绩` + `总成绩` → `分数类成绩 / 总成绩`），
再把它从数据里剔除。**仅在表头存在重名时补名**（那是"子列名丢了"的确定信号），
幂等（补过名后不再重名，下次只剔除不改名）。
`QueryStore.sanitize` 读取老存档时走同一逻辑 → 用户不刷新也能看到正确结果。

UI 侧（`QueryCards.pickGroup` / `isRealValue`）：
`0` / `-` / `无` / `N/A` 一律当占位值跳过；优先取「总成绩 / 总评 / 总分」，
其次「笔试 / 机试」，都没有才按表头顺序取第一个 —— 整组都没真实分数时就**不显示**这一行。
