### 🔴 .gitignore 的一个陷阱（本次新踩）
`build/` 这条规则会连带忽略**任何层级**下叫 `build` 的目录，
所以 `History/logs/build/` 整个目录被忽略了，刚归档进去的 23 份日志**进不了库**。
修法是**先把目录本身解禁，再解禁文件名**：

```gitignore
!History/logs/build/
km_build_v*.txt
!History/logs/build/km_build_v*.txt
```

只写最后一条不生效 —— git 的规则是「**父目录被排除时，无法靠否定规则
重新纳入其中的文件**」。判断用 `git check-ignore -v <路径>` 立刻能看到是哪条命中的。
