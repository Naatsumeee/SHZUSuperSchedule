## 石大课表 401 报错修复

用户反馈登录时报 `DioException [bad response]: 401`。

### 根因

Dio 的 `followRedirects: true` 在处理 CAS 登录重定向链（`authserver → sso.jsp?ticket → jwgl`）时，**中间 302 响应里的 `Set-Cookie`（jwgl 的 JSESSIONID）不会经过 `onResponse` 拦截器**，导致 jwgl 会话丢失，后续访问 `xsMain.htmlx` / `xskb_list.do` 返回 401。

### 修复（已改 `app_src/lib/`，重新出包成功）

1. **api_client.dart**：`BaseOptions` 改 `followRedirects: false` + `validateStatus: (s) => s != null && s < 500`（接受 3xx/4xx，手动处理）；新增 `getFollowRedirects(url, {query})` 手动跟随重定向（最多 12 跳），每一步都经过拦截器正确捕获 Set-Cookie；新增 `isRedirect()` 静态判断。
2. **auth_service.dart**：`loginWithPassword` 的 GET casLogin 检测到 302（已登录，有 TGT）直接返回 success；POST casLogin 后改用 `Location` 头判断（reAuthLoginView→needMfa / ticket=→success / authserver→failed），不再用 `realUri`（因为关闭了重定向）。`enterJwgl` 改用 `getFollowRedirects` 走完 casLogin→sso.jsp→jwgl 链路，并显式检测 401 返回友好错误。
3. **schedule_service.dart**：新增 `SessionExpiredException`；`fetchRaw` 检测 401/302 抛该异常。
4. **schedule_provider.dart**：`login` 检查 `enterJwgl` 返回值；`refresh` 捕获 `SessionExpiredException` → 提示"登录已过期"并置 `loggedIn=false`。

### 构建

复用 gradle-home 缓存，`BUILD SUCCESSFUL in 55s`，新版 `石大课表.apk`（54.4MB）已覆盖到项目根目录。

### 教训（可复用）

- Dio 手动管理 Cookie 时，**跨域 SSO 重定向链必须关 followRedirects 手动跟随**，否则中间 302 的 Set-Cookie 全丢。
- 判断登录流程走向，用响应头的 `Location`（而不是 realUri）。

## 修复 WebView 显示不正常 / 无法进入「学期理论课表」

用户反馈：WebView 进入教务系统显示不正常，选不到「学期理论课表」。

### 根因（实测确认，关键发现）

学校统一认证平台按 **User-Agent** 返回两套完全不同的页面：

| UA | 响应 | 页面 |
|---|---|---|
| 桌面 UA（Windows/Mac） | 200 / **24606 字节** | 无 `<meta viewport>`，固定宽度（login.css 有 width:340/416/500px，元素 top:160px / left:1119px 等绝对定位）|
| 移动 UA（Android/Mobile） | 200 / **14081 字节** | 有 `<meta name="viewport" content="width=device-width,user-scalable=no,initial-scale=1.0...">`，额外加载 `/gorgeous/static/mobile/css/index.css` + `weui.min.css` + `jquery-weui.min.css` |

原 `ImportPage.kt` **没有设置 `userAgentString`**，WebView 默认 UA 因 ROM 内核而异，常被判为桌面版 → 手机屏幕溢出、登录框出屏、菜单点不到。

### SSO 链路（实测）

```
HTTP https://jwgl.shzu.edu.cn/  → 302 Location: /sso.jsp
GET  https://jwgl.shzu.edu.cn/sso.jsp
     → 200，body 仅 156 字节：<script>window.location.href='http://authserver.shzu.edu.cn/authserver/login?service=https%3A%2F%2Fjwgl.shzu.edu.cn%2Fsso.jsp'</script>
HTTP authserver...login  → 302 → https://authserver...(HTTPS)
```
注意：**jwgl 是用 JS 跳转（不是 302）** 到 authserver 的，且 authserver 的 http 会 302 到 https。
未登录访问 `/jsxsd/xskb/xskb_list.do` → 302 `/jsxsd/sso.jsp` → 同样 JS 跳 authserver。
`authserver` 响应头有 `X-Frame-Options: DENY`（顶层导航不受影响）。

### 修复（`ui/ImportPage.kt` 已重写，BUILD SUCCESSFUL in 40s）

1. 显式 `settings.userAgentString = MOBILE_UA`（Android SM-G9910 Chrome 127 Mobile）→ 命中移动版登录页；
2. 缩放/视口：`useWideViewPort=true`、`loadWithOverviewMode=true`、`setSupportZoom(true)`、`builtInZoomControls=true`、`displayZoomControls=false`、`textZoom=100`；
3. `CookieManager.setAcceptThirdPartyCookies(webView, true)` + `setAcceptCookie(true)` → 保证 authserver↔jwgl 跨域 CAS 登录态；
4. `javaScriptCanOpenWindowsAutomatically=true` + `setSupportMultipleWindows(true)` + `onCreateWindow` 复用当前 WebView（解决 target=_blank 点了没反应）；
5. `cacheMode = LOAD_NO_CACHE` + `allowFileAccess/allowContentAccess`；
6. `onPageFinished` 注入 viewport meta 给无响应式老页面兜底；
7. UI 新增：`① 打开「学期理论课表」`（直达 `https://jwgl.shzu.edu.cn/jsxsd/xskb/xskb_list.do`）、`② 导入当前页面课表`，以及 **电脑版 / 手机版** UA 一键切换 + 刷新按钮；顶部显示 WebView 内核 Chrome 版本号。

### 产物

`石大课表_MiuiX版_WebView修复.apk`（14.6MB，release）。构建脚本已落盘为 `build_km.ps1`。

### 教训（可复用）

- **内嵌 WebView 抓学校/政务老系统，必须先 `curl` 对比桌面 UA vs 移动 UA 的响应大小与有无 `<meta viewport>`**，再决定 `userAgentString`；不要依赖 WebView 默认 UA。响应字节数差异（24KB vs 14KB）就是最快的判据。
- 移动版页面不一定有媒体查询（实测 `@media` 数 = 0），只是换了一套 CSS 目录（`/mobile/`）——判断依据是 viewport meta 而非 @media。
- 强智课表是宽带状表格，移动 UA 下会挤压，所以给了「电脑版」切换按钮。
