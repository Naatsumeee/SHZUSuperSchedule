# 石大超级课表 BETA-v1.3.2 使用说明

> Kotlin + Jetpack Compose + MiuiX 实现。安装包：`石大超级课表_BETA-v1.3.2.apk`
> 包名 `com.shzu.superschedule` · 版本 BETA-v1.3.2 · 作者 @Natsume

## 安装

传到安卓手机点击安装。从旧版（`com.shzu.classlist`）升级属于不同应用，需重新安装并重新导入课表。

## 一、导入课表

App 内不输账号密码，登录全部在学校官方网页完成。

1. 打开 App 首页即内嵌教务系统网页（`jwgl.shzu.edu.cn`）；
2. 在网页中正常登录（学号 / 密码 / 短信验证码）；
3. 点底部「**① 打开「学期理论课表」**」直达课表页；
4. 看到周次表格后点「**② 导入当前页面课表**」。
5. 表格显示不全时点「电脑版」，或双指缩放。

导入时**自动抓取**教务「学年学期」下拉框里的**全部学期**（无需手动选择），之后可在设置里直接切换。

> 采用移动端 UA 命中学校移动版登录页；导入课表时可一键切桌面 UA，避免宽带表格被挤压。

## 二、今日课程

- 顶部为 **「今日课程」大标题**，样式与周视图标题栏一致（22sp Medium，左对齐顶格）；
- 标题下为**紧凑日期条**：`9/18 周四` + `第 3 周` 胶囊 + 右侧统计；
- **只显示本周实际开课的课程**，非本周课程一律不进入当日课表（v1.3.1 同步周视图规则）；
- 字号比周视图**略大**一级，与周视图标题栏同款样式；
- 右侧统计为 **「N 门课」** + **「已上/共 N 节」**——门数按**课程名（学科）去重**统计，不是课时数；
  一门课最少占 2 课时，故一天最多 **5 门课 / 10 课时**；
- 每门课显示课程名、节次、时间、`@地点`、教师；已结束的右侧标注「已结束」；
- 同一时段有冲突的课，课程名右侧显示**橙色「冲突」胶囊角标**；
- 点击任意课程打开**课程详情**。

## 三、本周课表

**页面标题栏**
- 顶部为 **「本周课表」标题**，样式与今日课程页一致（22sp Medium，左对齐顶格）。

**10 行 × 7 列固定网格**
- 整张课表是一个 **10 行（1–10 节）× 7 列（周一–周日）** 的等距网格；
- **1–10 节的行距严格相等**（v1.3.1 修复间距不一致问题），侧边节次号与上下课时间的间距按统一标准排布；
- 「自定义课表样式」里的**「课程高度」滑块**统一调节所有课的高度（默认 52dp），
  课表以该固定高度为标尺划分网格，每格等高；
- 一门课占 N 个课时就**铺满 N 格**：2 课时渲染 2 格、3 课时渲染 3 格，以此类推（v1.3.1）；
- **所有课等高同宽渲染**，忽略课时之间的间隔时间（下课时间不占格），
  旧版「午休 / 晚休」分隔条已**完全移除**（v1.3.1）。

**网格线**
- 开启「显示网格线」后，在课表背景绘制**浅色虚线网格，横竖均有**；
- 竖线 7 条按 7 列等分，横线严格跟随「课程高度」滑块定出的等距行节奏；
- 侧边栏 1–10 节的时间与第 5–10 节的具体时刻按教务推断值显示，与实际一致。

**节次栏**（左侧）
- 数字 `1`–`10` 用黑色，上下课时间点（如 `10:00` / `10:45`）字号更小、颜色更浅，形成层次；
- 顶部保留 **「第 N 周」**与 `‹ ›` 切换。

**课程格**

- 内容**从顶部对齐**；显示顺序：课程名 → `@上课地点` → 教师；
- **同一节课连着多个课时会合并成一整长格**，中间不再切开；
- 文字默认**两端对齐（分散对齐）、字号 12**，均可在「自定义课表样式」里调整（BETA-v1.3.2 默认值）；
- **加粗课程名**默认使用 **Bold 字重**，可切换为 **Medium** 字重；
- **多教师课程**（如「贺亚玲,姜慧娇,宋瑞其」）默认只显示第一位教师，
  可在课程详情里**指定显示任意某一位**，或选择「全部」列出（BETA-v1.3.2）；
- **非本周课程**：格子背景淡化（默认强度 **25%**）、**文字同步淡化**，并在名字前**换行**加 **[非本周]**；
  淡化通过**与背景色混合**实现、**始终不透明**，因此开启网格线或格子边线后**不会被透出来**（BETA-v1.3.2 修复）；
  同一时间多条非本周课程会**合并为一个空位块**并标注涉及的周次（如 `11,13 周`），不再相互叠加；
- 开启**隐藏过长**后，课程名超过 **3 行**、教师名超过 **2 行**隐藏并显示省略号（BETA-v1.3.2）；
- **关闭「显示非本周课程」后，非本周课程不再出现在课表中**。

**交互**

- **点课程格** → 课程详情（周次、节次、地点、教师），可**删除本周这节课**（二次确认）；
- **点空白格** → 添加课程。弹窗顶部会**注明你点的是周几、第几节**（含上下课时间），默认为该位置，也可自定义；
- **时间冲突**：仅当**本周实际开课**的课程占用同一课时才算冲突，非本周的课不参与冲突判断；
  冲突格子右下角绘制**圆形底 + 白色感叹号的精致角标**；
- 点开有冲突的课程后，详情里的「**时间冲突**」区块**默认展开**（BETA-v1.3.2），
  直接列出该时段重叠的所有课程，并可**点任意一门「设为优先」**指定课表优先显示哪门；
  带「恢复自动裁决」按钮可还原；
  自动裁决规则：**占课时少的课程优先** —— 例如 1-2 节有 A、1-4 节有 B 时，
  1-2 节显示 A，第 3-4 节显示 B（BETA-v1.3.2）；
- 顶部 `‹ ›` 或左右滑动切换周次；日期条显示该周 7 天具体日期。

## 四、查询

不用开电脑，直接在手机上从教务系统读取**考试安排**与**成绩**。

三个入口，各自对应教务系统里的一条菜单路径：

| 入口 | 教务菜单路径 |
|------|--------------|
| 考试安排 | 考试报名 → 我的考试 → 考试安排查询 |
| 课程成绩 | 学籍成绩 → 我的成绩 → 课程成绩查询 |
| 等级考试成绩 | 学籍成绩 → 我的成绩 → 等级考试成绩 |

**使用步骤**

1. 点任意入口，进入后会内嵌打开教务系统，并**自动尝试跳到对应查询页**；
2. 若没有直接跳到目标页面，就在网页里按上表路径手动点进去；
   **登录状态与「导入课表」共用** —— 之前登录过就不用再登；
3. 当页面上出现数据表格后，点底部「**② 抓取当前页面**」，结果会以卡片列表展示；
4. 结果页顶部「**回网页**」可回到网页，重新定位或换了学期再抓一次。

**说明**

- 抓取的是「**当前页面**」上的表格，所以想换学期看考试/成绩，**先在网页里切学期再抓**；
- 查询结果目前**只保留在本次运行期间**（不落盘），重开 App 需重新抓取；
- 入口上会显示**上次抓取的时间与条数**，方便判断数据新旧；
- 教务改版导致表格识别不出时会明确提示，不会静默失败。

## 底部导航栏（全局）

底栏固定在屏幕底部，四个入口：**今日课程 / 本周课表 / 查询 / 设置**。切换时会**保留各页的滚动位置**。

- **真实背景高斯模糊**（BETA-v1.3.2）：底栏正**后方**的页面内容会被实时高斯模糊，
  而非仅仅叠一层不透明色块；课表滚到底栏下面时，能看到格子被磨砂糊化的效果。
  仅**背景**被模糊，**图标与文字始终清晰**，不会被糊到；
- **模糊半径沿栏高渐变**（BETA-v1.3.2）：栏底最糊（44dp），向上逐级变清（栏顶约 11dp），
  叠 5 层固定半径模糊层交叉淡出实现，避免整条一个糊度显得平板；
- **半透明渐变底色**：**顶边完全透明**、向下逐渐加深到 0.65，因此底栏与页面之间**没有可见的分界线**，
  只有"越往下越实"的过渡，磨砂感自然不突兀；顶部高光同样改为渐变（1px 实心白线会显得生硬）；
- 底栏**上方**不再出现多余的虚化带（BETA-v1.3.2 修复）；
- 模糊依赖 `RenderEffect`，**Android 12（API 31）及以上**生效；
  低于该版本自动降级为半透明底色（内容不被模糊），功能不受影响。

## 五、设置

设置页沿用 MiuiX 原生配置风格。所有分块小标题（「教务」「显示」「关于」等）均**居左顶格**，不再内缩。

**二级页面**
- 进入「自定义课表样式」「更新日志」等二级页面后，**页面顶部**有 `‹` 返回按钮，按系统返回键同样返回上一级；
- 页面切换带**方向感过渡动画**（进入右滑淡入、返回左滑淡出）；
- **预测性返回手势**：Android 13 (API 33) 及以上支持，可在设置「系统与交互」中开关。
  拖动手势时**上一级页面会实时跟着手指从左侧滑入**（当前页同步右移），
  **划到位时过渡即已完成**，松手直接确认；中途松手则平滑回弹（BETA-v1.3.2）；
- 在「自定义课表样式」里**切换底部导航去看课表再切回来，这个二级菜单不会关闭**，
  滚动位置也会保留，方便来回对照修改（BETA-v1.3.2）。

**教务**
- **当前学期** → 点「切换」可选其他学期；**无课表数据的学期置灰不可点**；
- **开学日期**（第一周周一）—— 调用**系统日期选择器**；
  若所选日期**不是周一**，会提示警告，提醒你核对第一周起始日；
- 重新导入课表 / **刷新可读学期**（**自动抓取**教务「学年学期」下拉框，无需手动选择）/ 数据更新时间 / **学科门数**（按课程名去重）。

**显示**（BETA-v1.3.2 起移到「教务」之后）
- **自定义课表样式** → 二级菜单，所有滑块与配色都收在这里，避免误触；
- 显示教师名字、显示非本周课程、标注 [非本周]。

**课表存档**（BETA-v1.3.2 起下移到「系统与交互」之前）
- **导出课表为 JSON** —— 通过系统文件选择器把当前学期课表存为 `.json` 文件，可用于备份或迁移；
- **导入课表 JSON** —— 从文件选择器选择 JSON 恢复；导入前会**严格校验文件结构**，
  缺字段 / 格式不对时会**警告并拒绝导入**，不会污染本地数据；
- 导入课表后本地自动保存为 JSON，**下次打开直接读取，无需重新导入**。

**系统与交互**
- **预测性返回手势**开关（Android 13+）；
- **上课提醒**开关 + 提前分钟数；
- **通知测试**（解锁彩蛋后出现，见下）—— 在「上课提醒」开启后用来**检查通知权限与渠道是否正常**，
  会显示当前权限状态并提供「去开启」入口，也可直接发送一条测试通知（BETA-v1.3.2）。
  测试通知会**随机取一节课**，按真实提醒的格式（课名 / 周几 · 地点 · 节次 · 时间）展示，
  右上角标注「通知测试」以便区分；**长按本项可关闭**（BETA-v1.3.2）。

**关于**
- **版本** → 点右侧「更新日志」查看**当前与历史版本更新记录**（全部带 `BETA-` 前缀）；
- 作者 `@Natsume`、反馈邮箱 `xu.tianhao@outlook.com`、数据来源、开源说明。
- **隐藏彩蛋**：**连续点击「开源说明」7 下**即可解锁「通知测试」选项（BETA-v1.3.2）；
  从第 3 次连点起会提示「还剩 x 次进入测试模式」（超出 2.5 秒未点则计数归零）；
  解锁后**长按「通知测试」**可再次隐藏，之后再连点「开源说明」7 下即可恢复；
- **反馈邮箱**：点**第一次**弹出 toast 提示「再次点击即可复制邮箱至剪切板」，
  点**第二次**把邮箱复制到剪贴板（BETA-v1.3.2）。

### 自定义课表样式（二级菜单）

**尺寸与间距**
- **课程高度**滑块（34–96dp，**默认 56dp**）—— 统一调节所有课的高度，同时决定网格行距；
- 字体大小（**默认 12**）、**文字与边界间距**（**默认 3**）；
- **文字对齐** → 默认**两端对齐**；MiuiX 原生**下拉菜单样式**（居中 / 居左 / 两端对齐）。

**网格与边框**（两个独立选项）
- **显示网格线**：在**课表背景按课时绘制浅色虚线网格**，竖线按**真实列布局**计算，
  与星期列**严格对齐**（BETA-v1.3.2 修复此前越靠右偏移越大的问题）；
- **显示课程格边框**：为每个课程格单独绘制细边框。

**文字样式**
- **加粗课程名字体**：开启使用 **Bold 字重**（默认），关闭使用 **Medium** 字重；
- **隐藏过长课程名**（超过 **3 行**省略）、**隐藏过长教师名**（超过 **2 行**省略）。

**非本周课程**
- **淡化强度**滑块（5–60%，默认 25%）——同时作用于格子背景与文字；
  淡化是**与课表底色混合、保持不透明**，所以不会漏出底层的网格线与格子边线（BETA-v1.3.2）。

**配色**
- **6 套预设配色集**：**马卡龙 / 莫兰迪 / 清透高饱和 / 石墨灰蓝 / 暖阳 / 冰川冷调**（带色卡预览）；
  **默认只陈列「马卡龙」**，**再点一下已选中的配色**才会展开其余（BETA-v1.3.2）；
  莫兰迪与石墨灰蓝已**整体提亮**（灰度过高会被误认为非本周课程），
  新增冷色调集**「冰川冷调」**与暖色的「暖阳」成对（BETA-v1.3.2）；
- **自定义配色合集**（BETA-v1.3.2）：关闭「使用预设配色集」会**自动创建一套「自定义 1」**，
  其颜色**默认复制马卡龙**，可**最多创建 3 套**、逐格修改 15 个颜色槽位，
  取色使用标准 HSL 色盘（色相条 + 饱和度 / 明度滑杆）；
- **自定义文字颜色**开关 + HSL 取色。
  设色时会**自动校验文字与格子背景的对比度**，若存在看不清的格子会弹窗提醒，
  可选择「**自适应文字色**」（对看不清的格子自动改用合适的文字色）或**保持**你的选择（BETA-v1.3.2）。

**重置**
- **恢复默认选项** —— 一键重置全部外观设置（回到 56dp / 12 / 3 等默认值），
  **不影响已导入的课表数据与自定义配色合集**。

## 六、桌面小组件

- 选择器里提供 **5 个尺寸条目**（v1.3.1）：**2×2 / 4×2 / 2×4 / 4×4** 四个固定档位 + **自适应尺寸**（可自由拖拽缩放）；
- **卡片高度随所选尺寸变化**（v1.3.1 修复高度固定不变的问题），内部行高按可用高度自动分配；
- 显示**今天的日期、星期、教学周**，以及**今日课程**（时间 + 名称 + 地点 + 颜色竖条）；
- 正在上的课颜色条会**高亮**；
- 今日无课时显示「今天没有课」；点小组件直接打开 App；
- 导入 / 切换学期 / 改设置后小组件自动刷新；
- 内置**加载态布局**：桌面重启或负一屏重载时先显示占位卡片，收到数据后切换为正式内容（符合小米官方规范）。

> v1.3.1 深度修复记录：此前小组件放到桌面后一直显示「载入窗口小部件时出现问题」灰块。
> 根因是布局里使用了 `<View>` 标签 —— 它不在 `RemoteViews` 允许膨胀的控件白名单里，
> 桌面端膨胀时抛出异常又被静默吞掉，于是永远停在灰块（而选择器预览走普通渲染路径，看起来一切正常）。
> 现已将色条 / 分隔线全部改用白名单内的 `ImageView`，并在推送前增加自检膨胀日志防止回归。

修复**预测性返回手势**：此前拖动手势时页面毫无预览跟随、松手才突然切页，现改为**手势进度实时驱动完整过渡** —— 底层上一级页面随手指从左侧归位、当前页同步右移，**划到位的那一刻过渡已经播完**，松手直接确认换页，不再补播一段动画；**网格线纵横轴与星期列严格对齐**（改用真实列布局计算，此前按 `宽度/7` 等分导致越靠右越偏）；**时间冲突课程进入详情默认展开**，无需二次点击；**底栏改为真实高斯模糊**（此前只是不透明平铺，现在会模糊底栏正后方的页面内容，半径 24dp，半透明底色 0.78→0.93 渐变；Android 12+ 生效，低版本降级为半透明底色），并修复底栏**上方**多出虚化带的问题；**非本周课程改为不透明淡化**（向背景色混合，不再因半透明透出底层网格线与格子边线）；默认值调整为**格子高度 56dp / 字号 12 / 文字与边界间距 3**；**隐藏过长**生效为课程名 3 行、教师名 2 行；**多教师课程可指定周视图只显示某一位教师**（或全部列出）；**时间冲突可自定义优先显示哪门课**（手动指定的课压过自动裁决，支持「恢复自动裁决」）；**莫兰迪 / 石墨灰蓝提亮**（灰度过高会被误认为非本周），新增冷色调集**「冰川冷调」**；**新增自定义配色合集**（最多 3 套，新建时复制马卡龙，15 个槽位逐格改色），配色集默认只陈列马卡龙、**再次点击已选配色展开其余**；自定义文字颜色时**自动校验与背景的对比度**，过低时弹窗让用户选择「自适应文字色」或保持；进入**自定义样式二级菜单后切换底部导航不再关闭该菜单**，方便来回对照；「今日课程」标题留白与字号**与「本周课表」完全一致**，设置页大标题遵循 MiuiX 规范；配置页分组顺序调整为 **教务 → 显示 → 课表存档 → 系统与交互 → 关于**；更新日志版本号统一加 `BETA-` 前缀；**隐藏彩蛋**：连续点击「开源说明」7 下解锁「**通知测试**」（在「上课提醒」中检查通知权限并发送测试通知）；**反馈邮箱**点一次 toast 提示「再次点击即可复制邮箱至剪切板」、点两次复制到剪贴板。

**BETA-v1.3.1**
周视图侧边 1–10 节次与时间**间距严格等距**，新增**课程高度滑块**（调节所有课的高度，并以该高度划分等距网格）；**移除午休 / 晚休分隔显示**，所有课**等高同宽**渲染、多课时合并铺满 N 格（2 课时 = 2 格）；**底栏模糊只作用于背景**，图标与文字不再被模糊；**导入课表后本地保存为 JSON**，下次启动直接读取；配置页新增**导出 / 导入课表 JSON**（导入前严格校验，不合格警告并拒绝）；修复**刷新可读学期无效**的问题（Cookie 路径）；课程名加粗默认 **Bold** 字重、可切换 **Medium**；课程格文字默认**两端对齐、字号 11**；「【非本周】」改为「**[非本周]**」，同一时间多条非本周课程**合并为一个空位块**并标注周次、不再叠加，本周视图不再渲染与本周课程重叠的非本周格子；**修复点击式下拉菜单闪退**（补齐 NavigationEventDispatcher）；**今日页恢复「今日课程」大标题**且只显示本周课程；**桌面小组件修复**：选择器提供 **2×2 / 4×2 / 2×4 / 4×4 / 自适应** 5 个条目，修复「载入窗口小部件时出现问题」（RemoteViews 布局禁用白名单外控件）、**卡片高度随尺寸自适应**、新增加载态布局；版本号 1.3.1。
